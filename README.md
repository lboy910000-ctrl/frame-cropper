# Frame Cropper

Offline desktop app. Pick a folder of screen recordings (no sound, up to 100+ min),
optionally draw a crop box, and it saves screenshots at a set interval while skipping duplicates.

## Download
Go to the **Actions** tab -> latest run -> **Artifacts**, or to **Releases** if a version tag was pushed.

## Run from source
    pip install -r requirements.txt
    python frame_cropper.py
